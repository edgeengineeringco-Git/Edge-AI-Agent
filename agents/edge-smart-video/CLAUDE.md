# EDGE Smart Video Content Agent

This agent produces LinkedIn-ready video content from a topic queue.

## Directory Structure

- `SYSTEM.md` — Agent identity and instructions
- `jobs/generate-content.md` — Content generation pipeline (the main job)
- `scripts/compose_video.py` — Professional text-first HTML video slideshow
- `scripts/generate_images.py` — Optional image generation (Pollinations or Nano Banana)
- `scripts/generate_video.py` — Veo 3.1 AI video generation (optional, needs GEMINI_API_KEY)
- `scripts/sheets_handler.py` — Google Sheets topic queue CRUD
- `scripts/drive_upload.py` — Google Drive upload of generated assets
- `output/` — Generated content per run

## Pipeline

1. Read pending topic from Google Sheets (via `sheets_handler.py`)
2. Generate LinkedIn post text and structured slide content using LLM
3. Optionally generate images (Pollinations free tier or Nano Banana) and Veo AI video
4. Run `scripts/compose_video.py` to produce professional HTML video slideshow (no API keys needed)
5. Upload all assets to Google Drive dated subfolder
6. Update sheet status to "Draft Ready"
7. Send Telegram notification with post preview

## Key Design Decision: Text-First Video

The primary video output is a **self-contained HTML slideshow** (`video.html`) — no API keys, no ffmpeg, no external dependencies needed. It features:

- Branded EDGE design (dark theme, cyan accents, Inter font)
- 3 slide types: title, content (animated bullets), CTA
- Progress bar, dot navigation, keyboard arrow controls
- Auto-advance every 5 seconds with smooth transitions
- Responsive, works on any browser

Structured slide content (`slides.json`) is the recommended input, generated by LLM from the LinkedIn post text.
