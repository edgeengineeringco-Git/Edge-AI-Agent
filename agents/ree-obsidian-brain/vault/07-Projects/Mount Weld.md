# Mount Weld

## Overview
**Mount Weld** (Western Australia) is Lynas' carbonatite-hosted REE deposit and one of the world's highest-grade REO resources (>15% TREO, LREE-dominated). It underpins Australia's non-China supply.

## Key Facts
| Property | Value |
|---|---|
| Operator | Lynas Rare Earths |
| Resource | >40 Mt @ ~15% TREO |
| REE | LREE (La, Nd, Pr, Ce) |
| Status | Producing |
