# Eudialyte

## Overview
**Eudialyte** is a complex cyclosilicate, **Na₁₅Ca₆(Fe,Mn)₃Zr₃Si₂₆O₇₂(OH,Cl)₂**, occurring in agpaitic (peralkaline) nepheline syenites. It is LREE- and Zr-rich and is targeted as a multi-element (REE + Zr + Nb) resource (e.g., Norra Kärr, Sweden).

## Key Facts
| Property | Value |
|---|---|
| Formula | Na₁₅Ca₆(Fe,Mn)₃Zr₃Si₂₆O₇₂(OH,Cl)₂ |
| REE | LREE-enriched, up to ~2–3% REO |
| Host | Peralkaline complexes |
| Co-product | Zirconium, niobium |
