# Bastnäsite

## Overview
Bastnäsite (also spelled bastnasite) is the world's most important REE ore mineral. It is a fluoro-carbonate mineral that dominates LREE production from carbonatite deposits. Bastnäsite is the primary mineral at Mountain Pass (USA) and Bayan Obo (China).

## Properties
| Property | Value |
|---|---|
| Formula | (Ce,La)CO₃F |
| Crystal System | Hexagonal |
| Hardness | 4–4.5 (Mohs) |
| Density | 4.9–5.2 g/cm³ |
| Colour | Honey-yellow, reddish-brown, wax-yellow |
| Lustre | Vitreous to greasy, pearly on cleavage |
| Streak | White |

## REE Content
Bastnäsite is strongly LREE-enriched:
| Element | Approx. % of REE |
|---|---|
| Ce | 49–51% |
| La | 33–34% |
| Nd | 11–12% |
| Pr | 3–4% |
| Sm | 0.5–1% |

**HREE**: <1% combined

## Occurrence
- **Carbonatites**: Primary bastnäsite in intrusive carbonatite (Mountain Pass, Bayan Obo)
- **Alkaline complexes**: Late-stage hydrothermal replacement
- **Pegmatites**: Rare, usually secondary
- **Associated minerals**: Monazite, parisite, synchysite, apatite, magnetite

## Processing
- **Flotation**: Selective flotation using fatty acid collectors at pH 8–9
- **Concentrate**: 50–70% REO
- **Leaching**: H₂SO₄ roast-acid leach at 90°C
- **Recovery**: 85–95%
