# Fluorapatite

## Overview
**Fluorapatite**, Ca₅(PO₄)₃F, is the common phosphate mineral and can host significant REE (up to several % REO) in **apatite-REE** (hydrothermal) deposits such as Strange Lake, Peace River, and parts of the Bayan Obo system.

## Key Facts
| Property | Value |
|---|---|
| Formula | Ca₅(PO₄)₃F |
| REE | LREE±HREE, substituting for Ca |
| Setting | Hydrothermal veins/breccias, carbonatites |
| Co-elements | Nb, Ta, F, Zr |
