# Monazite

## Overview
Monazite is a phosphate mineral and the second most important REE ore mineral after bastnäsite. It is LREE-enriched but contains significant thorium (typically 4–12% ThO₂), which creates regulatory challenges. Monazite occurs in carbonatites, alkaline complexes, and as placer concentrates in beach sands.

## Properties
| Property | Value |
|---|---|
| Formula | (Ce,La,Nd,Th)PO₄ |
| Crystal System | Monoclinic |
| Hardness | 5–5.5 (Mohs) |
| Density | **5.0–5.3 g/cm³** (heavy mineral) |
| Colour | Reddish-brown, yellowish-brown, orange, pink |
| Lustre | Resinous to vitreous, pearly on cleavage |
| Streak | White or pale yellow |

## REE + Th Content
| Component | Approx. % |
|---|---|
| Ce₂O₃ | 25–35% |
| La₂O₃ | 15–25% |
| Nd₂O₃ | 10–15% |
| ThO₂ | **4–12%** |
| P₂O₅ | 25–30% |

## Occurrence
- **Placer deposits**: Concentrated with ilmenite, rutile, zircon (India, Brazil)
- **Carbonatites**: Secondary to bastnäsite (Bayan Obo)
- **Pegmatites**: Large crystals, often radioactive
- **Granites**: Accessory mineral

## Radioactivity
Monazite is the primary source of Th in REE processing:
- **Activity**: 100–500 Bq/g in concentrate
- **Regulation**: >200 Bq/g = radioactive source material (license required)
- **Processing**: Caustic crack (NaOH) or acid leach (HCl)
- **Waste**: Th-bearing residue requires radioactive waste disposal

## Processing
- **Gravity**: Placer monazite concentrated by gravity/magnetic/electrostatic
- **Caustic crack**: NaOH at 300°C → 85–98% REE recovery
- **Acid leach**: HCl at 90°C → 90–98% REE recovery
