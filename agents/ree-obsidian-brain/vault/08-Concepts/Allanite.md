# Allanite

Epidote-group REE-bearing silicate (Ca,Ce,La,Y)₂(Al,Fe³⁺)₃(SiO₄)₃(OH). An important accessory REE host in granites and skarns; weathers easily, so a poor primary exploration target but a useful pathfinder.
