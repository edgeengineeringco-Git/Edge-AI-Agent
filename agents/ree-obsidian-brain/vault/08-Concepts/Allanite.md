# Allanite

Epidote-group REE mineral ((Ca,Ce,La,Y)₂(Al,Fe³⁺)₃(SiO₄)₃(OH)) common as an accessory phase in granitoids and metamorphic rocks. An important LREE host in some carbonatite and alkaline systems.
