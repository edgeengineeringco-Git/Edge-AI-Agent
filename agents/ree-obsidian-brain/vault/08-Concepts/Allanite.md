# Allanite

## Overview
Allanite is an epidote-group sorosilicate, **(Ca,Ce,La,Y)₂(Al,Fe³⁺)₃(SiO₄)₃(OH)**, and an important accessory REE host in granitic, syenitic, and pegmatitic rocks. High REE + Th content makes it metamict (radiation-damaged) and often weakly magnetic.

## Key Facts
| Property | Value |
|---|---|
| Formula | (Ca,Ce,La,Y)₂(Al,Fe³⁺)₃(SiO₄)₃(OH) |
| REE | LREE-dominant (Ce,La) + Y |
| Setting | Granites, pegmatites, alkaline complexes |
| Issue | Metamict, Th-bearing, refractory to process |
