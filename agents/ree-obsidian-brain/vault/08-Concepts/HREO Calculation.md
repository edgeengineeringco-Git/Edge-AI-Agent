# HREO Calculation

Heavy Rare Earth Oxide = TREO contribution from Gd, Tb, Dy, Ho, Er, Tm, Yb, Lu (and commonly Y). Expressed as HREO/TREO % to gauge the strategic value of a resource; HREE command large price premiums.
