# TREO Calculation

## Overview
**TREO (Total Rare Earth Oxide)** is the sum of all rare earth oxide equivalents, the standard headline grade for REE deposits.

## Formula
> TREO = La₂O₃ + CeO₂ + Pr₆O₁₁ + Nd₂O₃ + Sm₂O₃ + Eu₂O₃ + Gd₂O₃ + Tb₄O₇ + Dy₂O₃ + Ho₂O₃ + Er₂O₃ + Tm₂O₃ + Yb₂O₃ + Lu₂O₃ + Y₂O₃ + Sc₂O₃
