# CREO Calculation

Critical Rare Earth Oxide = Nd₂O₃ + Pr₆O₁₁ + Dy₂O₃ + Tb₄O₇ + Eu₂O₃. A supply-risk-weighted tonnage proxy that captures the elements with the tightest substitution and the highest strategic premium.
