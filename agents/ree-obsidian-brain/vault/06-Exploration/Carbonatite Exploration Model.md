# Carbonatite Exploration Model

Targeting signature: positive magnetic + gravity, Th/Nb/P anomalies, fenitisation halo, and dolomite/sovite carbonatite intrusions. Best REE grades in weathered/orgenic carbonatites (Bayan Obo, Mountain Pass).
