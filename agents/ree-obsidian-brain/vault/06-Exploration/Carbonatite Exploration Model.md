# Carbonatite Exploration Model

## Overview
The **carbonatite exploration model** targets REE in carbonatite complexes using geological, geophysical, and geochemical criteria.

## Criteria
- Circular/annular intrusions, fenitization aureoles
- Strong **magnetic** + gravity highs; high Th/K radiometrics
- LREE-bearing bastnäsite/monazite/pyrochlore
- Pathfinders: Nb, Zr, P, Th
