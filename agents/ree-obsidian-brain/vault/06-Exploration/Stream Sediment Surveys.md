# Stream Sediment Surveys

## Overview
**Stream sediment surveys** use drainage-basin sediment REE/pathfinder geochemistry for regional reconnaissance, ranking catchments for follow-up.

## Use
- First-pass basin prioritization
- Integrates upstream mineralization
- Cheap, wide coverage
