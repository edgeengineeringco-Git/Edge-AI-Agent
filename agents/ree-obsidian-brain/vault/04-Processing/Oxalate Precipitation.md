# Oxalate Precipitation

## Overview
**Oxalate precipitation** drops REE oxalates from solution at controlled pH; calcining yields high-purity REE oxides. It is a classic refining/purification step.

## Key Facts
- REE³⁺ + (COOH)₂ → REE₂(C₂O₄)₃↓
- Calcination → REE₂O₃
- Removes non-REE impurities
