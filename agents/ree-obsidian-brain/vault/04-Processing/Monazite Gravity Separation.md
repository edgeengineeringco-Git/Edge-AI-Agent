# Monazite Gravity Separation

## Overview
**Monazite gravity separation** recovers heavy monazite from placer sands using gravity (spiral, shaking table), magnetic, and electrostatic circuits to separate it from ilmenite, rutile, and zircon.

## Flow
Beach sand → spiral/gravity → magnetic → electrostatic → monazite concentrate → [[Oxalate Precipitation]] / caustic crack
