# 📎 Attachments

Drop your PDFs, Excel files, images, and any other attachments here.

## How This Works

| File Type | What Happens |
|-----------|-------------|
| **Images** (`.png`, `.jpg`, `.svg`) | ✅ Synced to GitHub automatically |
| **Small PDFs** (<25 MB) | ⚠️ Blocked by Git — upload to Google Drive instead |
| **Excel** (`.xlsx`, `.xls`) | ⚠️ Blocked by Git — upload to Google Drive instead |
| **Word** (`.docx`, `.doc`) | ⚠️ Blocked by Git — upload to Google Drive instead |

## For Large Files (PDFs, Excel, etc.)

1. Drag the file into this folder in Obsidian (it works locally)
2. Also upload a copy to Google Drive: https://drive.google.com/drive/folders/1TeA2-iAs5QLYK1cpT8HWbMeDAxWFHUf7
3. Reference it in your notes with the Drive link

## Obsidian Links

To embed an attachment in a note, use:

```
![[filename.png]]
```

For a Drive-hosted PDF, link it:

```
[Paper Title](https://drive.google.com/file/d/FILE_ID/view)
```
