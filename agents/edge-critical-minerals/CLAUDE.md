# EDGE Critical Minerals Intel Agent

This agent produces weekly intelligence briefs on critical minerals markets, geopolitics, and technology.

## Directory Structure

- `SYSTEM.md` — Agent identity and instructions
- `jobs/weekly-report.md` — Pipeline definition (web intel → analysis → report)
- `reports/` — Generated weekly reports

## Pipeline

The weekly pipeline runs every Monday at 9:00 AM via CRONS.json. It:
1. Gathers web intelligence across 8 domains (lithium, REEs, cobalt/nickel, copper, graphite, policy, geopolitics, technology)
2. Analyzes and synthesizes findings
3. Generates a structured markdown report at `reports/YYYY-MM-DD-weekly-report.md`

## First Report

The initial report (2026-05-18) was generated by the setup job. Subsequent reports will be produced by the scheduled weekly cron.
