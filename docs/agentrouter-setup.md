# AgentRouter Integration Guide

This guide replicates the setup from the LinkedIn post to give your thepopebot agents free access to **Claude Opus**, **GPT-5.5**, and **GLM-5.2** via AgentRouter's $175 API credit.

---

## Step 1: Sign Up & Get API Key

1. Go to **https://agentrouter.org**
2. Click **"Sign in with GitHub"** (your GitHub is already connected)
3. Navigate to **API Token** in the dashboard
4. Create a new key:
   - **Name:** `thepopebot-litellm`
   - **Quota:** Select **Unlimited**
   - **Model restrictions:** Enable all models you want:
     - `claude-opus-4-8`
     - `claude-opus-4-7`
     - `claude-opus-4-6`
     - `gpt-5.5`
     - `glm-5.2`
5. **Copy the API key** — it starts with something like `ar-...`

---

## Step 2: Add API Key to Environment

Paste your key into the project's `.env` file:

```bash
# AgentRouter (OpenAI-compatible endpoint)
AGENTROUTER_API_KEY=ar_your_key_here
```

> If `.env` does not exist yet, create it in the repo root.

---

## Step 3: Merge LiteLLM Config

Open **`event-handler/litellm/main.yaml`** and **append** the contents of `litellm-agentrouter.yaml` (located in repo root) to the `model_list:` array.

Your final `main.yaml` should look like this:

```yaml
# LiteLLM proxy config. Docs: https://docs.litellm.ai/docs/

model_list:
  - model_name: deepseek-chat
    litellm_params:
      model: openai/deepseek-chat
      api_key: ${DEEPSEEK_API_KEY}
      api_base: https://api.deepseek.com/v1

  # AgentRouter — $175 free credit
  - model_name: claude-opus-4-8
    litellm_params:
      model: openai/claude-opus-4-8
      api_key: ${AGENTROUTER_API_KEY}
      api_base: https://agentrouter.org/v1

  - model_name: claude-opus-4-7
    litellm_params:
      model: openai/claude-opus-4-7
      api_key: ${AGENTROUTER_API_KEY}
      api_base: https://agentrouter.org/v1

  - model_name: claude-opus-4-6
    litellm_params:
      model: openai/claude-opus-4-6
      api_key: ${AGENTROUTER_API_KEY}
      api_base: https://agentrouter.org/v1

  - model_name: gpt-5.5
    litellm_params:
      model: openai/gpt-5.5
      api_key: ${AGENTROUTER_API_KEY}
      api_base: https://agentrouter.org/v1

  - model_name: glm-5.2
    litellm_params:
      model: openai/glm-5.2
      api_key: ${AGENTROUTER_API_KEY}
      api_base: https://agentrouter.org/v1
```

---

## Step 4: Restart LiteLLM Proxy

Restart the thepopebot stack so LiteLLM picks up the new config:

```bash
docker compose restart litellm
# or full restart:
docker compose up -d --force-recreate
```

---

## Step 5: Use in Agent Jobs

Once restarted, any agent in this project can call these models via the LiteLLM proxy.

Example: to make an agent use `claude-opus-4-8`, set its model environment variable or pass it in the job configuration to point at the LiteLLM proxy with `model="claude-opus-4-8"`.

## Claude Code CLI (Local Machine)

If you also want **Claude Code** on your local laptop to use AgentRouter:

```bash
# 1. Install Claude Code (if not already)
npm install -g @anthropics/claude-code

# 2. Set environment variables
export ANTHROPIC_BASE_URL=https://agentrouter.org/v1
export ANTHROPIC_API_KEY=ar_your_key_here

# 3. Run in your project directory
claude
```

Claude Code will now route through AgentRouter and use your $175 credit.

## VS Code + Kilo Code Extension

1. Install **Kilo Code** from the VS Code marketplace
2. Open **Settings** → **Providers** → **Custom Providers**
3. Add:
   - **Provider ID:** `agentrouter`
   - **Display Name:** `AgentRouter`
   - **Provider API:** `Anthropic Messages`
   - **Base URL:** `https://agentrouter.org/v1`
   - **API Key:** your `ar_...` key
4. Add each model with identical **ID** and **Name**:
   - `claude-opus-4-8`
   - `claude-opus-4-7`
   - `claude-opus-4-6`
   - `gpt-5.5`
   - `glm-5.2`
5. Click **Submit**

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `401 Unauthorized` | Check that `AGENTROUTER_API_KEY` is correct and not expired |
| `Model not found` | Verify the model name matches exactly what's enabled in your AgentRouter dashboard |
| LiteLLM won't start | Validate YAML indentation (2 spaces). Use `yamllint` if needed |
| Credit exhausted | AgentRouter gives $175 initial credit. After that you must fund the account |
