6-Layer Pipeline

Logic Chain Architecture

Geology as the primary predictor \u2014 OneGeology lithology drives K/U/Th estimation globally, with measurements refining the prior where available.

\U0001f4e5

Layer 1 \u2014 INGEST

Fetch per bounding-box: OneGeology WFS (primary), Sentinel-2 composites, GLO-30 DEM + hillshades, GEM faults, SoilGrids, FOREGS geochemistry, JRC Atlas, airborne radiometric (if available). Cache to PostGIS with provenance.

\U0001f52c

Layer 2 \u2014 FEATURE EXTRACTION

Lithology class per polygon from OneGeology. K/U/Th via LITHOLOGY_ACTIVITIES lookup (primary), with override from airborne radiometric / geochemical atlas \u2192 ppm eU (\u00d712.22), eTh (\u00d74.06), %K (\u00d7313) \u2192 Bq/kg. Lineament density from DEM + Sentinel-2 + GEM faults.

\u2699\ufe0f

Layer 3 \u2014 DOSE MODELS

All calculations via dose_calculation_core.py v4. External gamma (UNSCEAR coefficients), Geogenic Radon Potential (GRP), Global Thoron Potential (GTP). Measured CRn/CTn override geogenic estimates.

\U0001f6a6

Layer 4 \u2014 RISK CLASSIFICATION

Traffic-light system: dose \u22642.2 / 2.2\u20136.6 / >6.6 mSv/yr; radon <100 / 100\u2013300 / \u2265300 Bq/m\u00b3; gamma <59 / 59\u20131000 / \u22651000 nGy/h; Ra-eq <370 / 370\u2013740 / \u2265740 Bq/kg. Flags: WHO, EU BSS, UNSCEAR upper-normal.

\u25b3

Layer 5 \u2014 VISUALISATION

VisQuill-style dose fingerprint triangle per polygon: arms = radon / thoron / gamma (mSv/yr). Colour by dominant source. Risk traffic-light overlay. Provenance panel: geology prior vs measured per parameter + confidence score.

\U0001f916

Layer 6 \u2014 AGENT LOOP

Coverage-gap detection (\u201cno airborne eTh \u2192 using lithology prior for Th/thoron\u201d). Confidence scoring per polygon. Provenance logging for paper-readiness. Threshold alerts.

Reference Formulas

Core dosimetric equations implemented in dose_calculation_core.py v4. All coefficients from UNSCEAR 2024, ICRP 137, and EU BSS.

External Gamma Dose Rate

UNSCEAR 2000 / 2024 \u2014 Activity-to-dose conversion
D_air (nGy/h) = 0.462 \u00d7 A_Ra + 0.604 \u00d7 A_Th + 0.041 \u00d7 A_K

Where A_Ra = Ra-226 activity (Bq/kg), A_Th = Th-232 activity (Bq/kg), A_K = K-40 activity (Bq/kg). Coefficients from UNSCEAR gamma dose conversion factors.

E_ext (mSv/yr) = D_air \u00d7 8760 \u00d7 OF \u00d7 0.7 \u00d7 10\u207b\u2076

8760 = hours/year; OF = occupancy fraction; 0.7 = Sv/Gy conversion for effective dose; 10\u207b\u2076 = nGy to Gy.

Geogenic Radon Potential (GRP)

ICRP 137 \u00b7 EU BSS 2013/59/Euratom
C_Rn_indoor = A_Ra \u00d7 \u03c1_soil \u00d7 \u03b7 \u00d7 f_fault \u00d7 perm_factor \u00d7 (1/(EF+ALR)) \u00d7 k_struct

A_Ra = Ra-226 source (Bq/kg) from lithology prior; \u03b7 = emanation coefficient (0.1\u20130.3); f_fault = proximity-to-fault enhancement; perm_factor = soil permeability; EF = enclosure factor; ALR = air change rate.

E_Rn (mSv/yr) = GRP \u00d7 K_Rn
GRP = A_Ra \u00d7 perm \u00d7 fault_enhance
K_Rn = 0.035 (calibrated vs UNSCEAR world avg)

WHO reference level: 100 Bq/m\u00b3. EU BSS: 300 Bq/m\u00b3 action level.

Global Thoron Potential (GTP)

Geogenic from Th-232 \u00b7 No global measurement network
C_Tn_indoor = A_Th232 \u00d7 \u03b7_Tn \u00d7 perm_factor \u00d7 k_struct
\u03b7_Tn = emanation (0.1 \u2013 0.3) for thoron
EEC_Tn = C_Tn \u00d7 0.02 (equilibrium factor)

No global thoron measurement network \u2192 estimated geogenically from Th-232. Calibrated so world-average soil yields ~0.1 mSv/yr. In Th-rich terrains (monazite/REE), thoron becomes a dominant arm \u2014 critical for REE prospectivity.

E_Tn (mSv/yr) = Tn_source \u00d7 K_Tn
Tn_source = A_Th232 \u00d7 \u03b7 \u00d7 perm
K_Tn = 0.25 (calibrated: Th-rich terrains flag REE prospectivity)

Th-232 \u2192 emanation (0.1\u20130.3) \u2192 indoor gas \u2192 EEC (\u00d70.02) \u2192 dose (\u00d740 nSv \u00d7 7000h).
