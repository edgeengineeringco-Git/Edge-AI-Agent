# L4 — Tellus airborne Magnetics (TMI + analytic signal)

**Status: NULL** (2026-09-13) — blocked by environment, NOT by data non-existence.

## What was confirmed
- The GSI Geophysics service `IE_GSI_GSNI_Magnetic_Intensity_50m_IE32_ITM_GRID` (MapServer)
  **exists**, CRS = EPSG:2157 (ITM), 50 m, and its extent covers all of Ireland (ROI+NI).
  So the layer is real and nationally complete.

## Why it is NULL (raw values unretrievable here)
- `export` returns a rendered **PNG** (colormap), not raw nT.
- `identify` returns the renderer's **RGB**, not the value.
- WMS `GetFeatureInfo` is disabled; no `ImageServer` variant; **WCS is not enabled** (returns the
  REST directory page). No downloadable magnetic grid is listed on data.gov.ie or gsi.geodata.gov.ie.
- GDAL/WCS cannot be installed (non-root container, PEP 668).
- Unlike radiometric L1–L3, **no derived raw magnetic product exists** in the project to fall back on.

Retries (export, identify, WMS, WCS, data.gov.ie file search) exhausted → FAILED → **NULL**.

## Resolution required before L4 can be CONFIRMED
1. Run in a root-enabled environment with GDAL, then pull via WCS / ESRI REST
   (`export` with an identity renderer or `query` on the raster catalog); OR
2. Supply a raw magnetic grid file (GeoTIFF/ERS/BIL) or a mirror URL.

Per protocol, no layer past L4 may be confirmed while L4 is NULL. L5–L18 are deferred
pending the L4 resolution above (or an explicit override from the user).
